# Exemplo de skill local

Use esta skill quando o pedido envolver organizar uma tarefa, resumir um plano
ou definir próximos passos de forma objetiva.

- Identifique o resultado desejado e as restrições já informadas.
- Responda com uma sequência curta de ações concretas.
- Preserve as escolhas do usuário e sinalize suposições relevantes.
- Não crie arquivos, altere sistemas ou execute ações externas sem que isso
  esteja explicitamente no escopo do pedido.

Esta é uma skill mínima de demonstração para o diretório `.agents/skills`.
